DellNative now reads toner levels from the printer and shows them on the web
supplies page at http://localhost:8631/. It also publishes cartridge names,
colors, and percentages through IPP for clients such as macOS. Unavailable
readings are reported as unknown instead of an estimated 50 percent.

Enable SNMP v1 with the read community `public` on the printer and allow UDP
port 161 from the Mac. Custom communities and SNMP v3 are not supported.
Printing remains available when SNMP supply queries fail.

Download and unzip DellNative-0.4.0.zip, then run Install.command to update an
existing installation or install a new one. The ZIP includes corresponding
source, dependency archives, patches, and notices; the accompanying .sha256
file verifies the download.

Validated with a physical C1765nfw: all four toner readings matched the printer's
SNMP supply table and appeared in IPP responses and the web supplies page.
The clean native build, supply callback regression tests, and all 10 printer
discovery tests passed. No pages were printed for this update. The macOS supply
display and a full installer update cycle have not been validated for 0.4.0.

Experimental Apple-silicon build. Packages are ad-hoc signed, not Developer ID
signed or notarized. See the README for compatibility and installation details.
