The printer service now runs without the generic folder icon in the macOS menu
bar. Printing and automatic login startup continue in the background. Printer
status and settings remain available at http://localhost:8631/.

Download and unzip DellNative-0.3.1.zip, then run Install.command to update an
existing installation or install a new one. Bonjour finds the C1765nfw for you.
The ZIP includes corresponding source, dependency archives, patches, and notices;
the accompanying .sha256 file verifies the download.

Experimental Apple-silicon build. Packages are ad-hoc signed, not Developer ID
signed or notarized. Earlier releases were physically tested for color and
multipage monochrome printing on a C1765nfw with macOS 27. This update changes
service UI startup, not raster conversion. macOS 28 is not yet validated.

Validated locally on macOS 27: installation and service restart without a
menu-bar app, all 10 discovery tests, and two-page color/monochrome capture tests
for both PWG and Apple Raster. No physical pages were printed for this update.
